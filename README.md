# LSAHR Dataset

## Description
Large-Scale Arabic Hotel Review Dataset containing 292,460 
reviews for sentiment analysis and personalized recommendation.

## Dataset Statistics
- Reviews: 292,460
- Hotels: 502
- Users: 176,285

## Versions
- Unbalanced version: 292,460 reviews
- Balanced version: 122,679 reviews

## Files
- `lsahr_unbalanced.csv` — full dataset
- `lsahr_balanced.csv` — balanced version
