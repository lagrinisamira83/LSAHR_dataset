# LSAHR Dataset

## Description
Large-Scale Arabic Hotel Review Dataset containing 292,460 
reviews for sentiment analysis and personalized recommendation.

## Dataset Statistics
- Reviews: 292,460
- Hotels: 502
- Users: 176,285

## Versions
- Unbalanced version: 292,460 reviews
- [Download Dataset](https://drive.google.com/uc?export=download&id=1BdrVWDfyMPA2XYZu08teVJxYYsB28pzv)
- Balanced version: 122,679 reviews
- [Download Dataset](https://docs.google.com/spreadsheets/d/1iHvf64M4KeiPQcKJrLTDFDnLuUew8pJy/export?format=xlsx)

## Files
- `lsahr_unbalanced.csv` — full dataset
- `lsahr_balanced.csv` — balanced version (not annotated)
- `lsahr.csv` — balanced version (annotated version)
